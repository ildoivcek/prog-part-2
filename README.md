# Розташування агресивних корів (Варіант 3)

## Умова завдання
Фермер Джон побудував новий довгий загін для худоби з `N` (2 <= N <= 100,000) секцій. Секції розташовуються уздовж прямої лінії в положеннях `x1, ..., xN` (0 <= x_i <= 1,000,000,000).

Його `C` (2 <= C <= N) корів не люблять нову будівлю і стають агресивними одна до одної, коли вони розміщені в сусідніх стійлах. Щоб уникнути ситуації, коли корови можуть заподіяти шкоду одна одній, фермер хоче розташувати агресивних корів у стійлах таким чином, щоб мінімальна відстань між будь-якими з них була настільки великою, наскільки це можливо. 

**Мета:** Знайти найбільшу можливу мінімальну відстань між коровами.

## Приклад роботи алгоритму

* **Вхідні дані:** * `N = 5` (кількість секцій)
  * `C = 3` (кількість агресивних корів)
  * `free_sections = [1, 2, 8, 4, 9]`
* **Результат:** `3`

**Пояснення:** У фермера є 5 стійл, у яких потрібно розмістити 3 корови. Їх можна розташувати в стійлах `1, 4 та 8` або `1, 4 та 9`. В обох випадках найменша відстань між коровами (між 1 і 4) дорівнює 3. Таким чином, мінімальне значення максимальної дистанції становить `3`.

## Підказка
Оскільки у нас є щонайменше дві корови, найкраще, що ми можемо зробити, це розташувати їх у загоні у першому вільному стійлі і в самому кінці (попередньо відсортувавши масив позицій).

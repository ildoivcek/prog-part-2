## Лабораторна робота №5 (Варіант 3 Рівень 3)
# Обчислення кількості островів

## Опис завдання
У даній роботі реалізовано алгоритм підрахунку кількості островів у заданій двійковій матриці. 

За умовою, матриця складається з елементів `0` (вода) та `1` (суша). Острів визначається як сукупність сусідніх елементів `1`, з'єднаних між собою по горизонталі або вертикалі або діагоналі. Мета алгоритму — знайти загальну кількість таких ізольованих компонент зв'язності (островів) на полі.

## Вхідні параметри
- **Двійкова матриця** (у базовому сценарії використовується розмір 8х8).
- **Стартова точка** (наприклад, `7, 0` — рядок 7, стовпець 0) для ініціалізації обходу графа.

## Реалізація та тестування
- Алгоритм базується на обході матриці (пошук у глибину/ширину) для виявлення та маркування всіх з'єднаних ділянок суші.
- Коректність роботи алгоритму, включно з крайовими випадками (повна відсутність суші, суцільна суша, задана кількість островів), перевірена за допомогою модульних тестів (бібліотека `unittest`).

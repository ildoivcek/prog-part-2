## Лабораторна робота №1 (Варіант 3 Рівень 3)
​# Знахідка найдовшої пікової підпослідовності (Longest Peak)

## Умова завдання
Напишіть функцію, яка приймає невпорядкований масив цілих чисел і повертає довжину найдовшої пікової підпослідовності. Якщо масив містить декілька пікових підпослідовностей, алгоритм повинен знайти та повернути довжину максимальної з них.

## Що таке пікова підпослідовність?
Для формування пікової підпослідовності необхідно мінімум **3 числа**. 

Пікова підпослідовність визначається як послідовність чисел, яка починається з меншого числа, після чого наступне число строго більше попереднього, поки вони не досягнуть вершини (максимального значення у підпослідовності). Всі значення після досягнення вершини мають бути завжди строго меншими від свого попередника.

### Приклади:
* `1, 7, 2` — є піковою підпослідовністю (де `7` — вершина).
* `1, 2, 3` — **не є** піковою послідовністю (немає спадної правої частки).
* `3, 2, 1` — **не є** піковою полідовністю (немає зростаючої лівої частки).
* `-1, -5, -1` — **не є** піковою послідовністю (це впадина, а необхідно знайти вершину).

## Приклад роботи алгоритму

* **Вхідний масив:** `[1, 3, 5, 4, 2, 8, 3, 7]`
* **Результат:** `5`
* **Пояснення:** Знайдена найдовша пікова підпослідовність — це `1, 3, 5, 4, 2`, яка має довжину 5.

## Вимоги до тестування
Для перевірки коректності роботи алгоритму використовується вбудована бібліотека `unittest`. Покриті наступні сценарії тестування:
1. Всі елементи масиву посортовані за зростанням.
2. Всі елементи масиву посортовані за спаданням.
3. Масив містить лише 2 елементи.
4. Масив не містить жодної пікової підпослідовності.
5. Масив містить рівно 3 пікові послідовності.

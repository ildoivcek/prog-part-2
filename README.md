
# Лабораторні роботи з дисципліни "Алгоритми та структури даних"
​
## Виконала: Перфілова Ганна Русланівна (ІР-11)
​
## Лабораторна робота №6 (Варіант 3 Рівень 3)
# Опис завдання
У даній роботі реалізовано алгоритм перевірки можливості транспортування газу від газосховищ до міст по мережі активних газопроводів.

За умовою, мережа моделюється як орієнтований граф, де вершинами є міста та сховища, а ребрами — труби. Шлях постачання визначається як послідовність населених пунктів, з'єднаних активними газопроводами, по яких газ може рухатися лише в одному заданому напрямку (можливий транзит). Мета алгоритму — перевірити доступність міст та знайти для кожного сховища список міст, до яких неможливо доставити паливо (або повернути пустий список, якщо всі міста досяжні).

Вхідні параметри
Списки міст та газосховищ (назви населених пунктів та точок відправлення газу).

Список активних газопроводів (наприклад, ['Львів', 'Стрий'] — означає наявність труби, де подача газу відбувається від Львова до Стрия).

Реалізація та тестування
Алгоритм базується на обході орієнтованого графа (пошук у глибину/ширину) для виявлення та маркування всіх досяжних міст, починаючи обхід з кожного окремого газосховища.

Коректність роботи алгоритму, включно з крайовими випадками (повна відсутність зв'язку, всі міста досяжні з усіх сховищ, наявність складних транзитних маршрутів), перевірена за допомогою модульних тестів (бібліотека unittest).

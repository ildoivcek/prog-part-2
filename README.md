## Лабораторна робота №4 (Варіант 3 Рівень 2)
# Черга з пріоритетами на основі бінарного дерева (Priority Queue)

## Умова завдання
Реалізуйте структуру даних «черга з пріоритетами» (Priority Queue), використовуючи **бінарне дерево** (Binary Tree). 

Дерево повинно будуватися за специфічними правилами порівняння пріоритетів:
* Батьківський елемент має **вищий** пріоритет, ніж елемент **справа**.
* Батьківський елемент має **нижчий або рівний** пріоритет, ніж пріоритет його **лівої** дитини.


## Операції
Реалізована структура даних повинна підтримувати такі базові операції:
1. **Вставка (Insert):** Додавання нового елемента із заданим значенням та пріоритетом. Елемент має бути розміщений у правильному місці дерева для збереження вказаної вище ієрархії пріоритетів.
2. **Витягування (Extract-Max):** Знаходження, видалення та повернення елемента з найвищим пріоритетом з черги.
3. **Перегляд (Peek):** Отримання значення елемента з найвищим пріоритетом без його видалення (без зміни самої черги).

## Вимоги до структури даних
Для побудови черги з пріоритетами необхідно реалізувати допоміжний клас `Node` (Вузол). Кожен об'єкт цього класу повинен містити щонайменше два основних поля:
* `value` — дані/значення, які зберігає елемент.
* `priority` — числове значення пріоритету, за яким визначається місце вузла в дереві.

# Опис завдання
У даній роботі реалізовано алгоритм для розв'язання лінгвістичної задачі "Ланцюжок зі слів" (Код задачі: WCHAIN).

За умовою гри, із заданого списку з N слів перший гравець обирає довільне слово w1 і викреслює з нього одну довільну літеру так, щоб отримати інше слово w2 з цього ж списку. Після цього хід переходить до іншого гравця, і він намагається зробити те саме зі словом w2. Гра завершується в одному з двох випадків:
* Залишається слово з однієї літери.
* Неможливо викреслити жодну літеру так, щоб отримати інше слово зі словника.

Мета алгоритму — визначити довжину максимального ланцюжка слів, якого можна досягти в цій грі при заданих словах.

### Вхідні дані
Вхідний файл `wchain.in` складається з N + 1 рядків:
* Перший рядок містить N — кількість слів у словнику, 1 ≤ N ≤ 10⁵.
* Кожен з наступних N рядків містить слово довжиною від 1 до 50 символів, яке складається з малих латинських літер від a до z.

### Вихідні дані
Вихідний файл `wchain.out` повинен містити одне число — довжина максимального ланцюжка.

## Реалізація та тестування
Алгоритм базується на методі **динамічного програмування (Dynamic Programming)** та попередньому сортуванні слів за їхньою довжиною.

**Основні етапи алгоритму:**
1. **Сортування та індексація:** Усі слова завантажуються у структуру даних (наприклад, множину або хеш-таблицю) для швидкого пошуку за O(1) та сортуються за зростанням їхньої довжини. Це гарантує, що для будь-якого поточного слова всі його потенційні підслова меншої довжини будуть оброблені раніше.
2. **Обчислення динаміки:** Створюється структура (хеш-карта) `dp`, де для кожного слова зберігається максимальна довжина ланцюжка, що закінчується цим словом. Базове значення для кожного слова дорівнює 1.
3. **Генерація підслів:** Для кожного слова довжиною L послідовно видаляється кожна літера (генерується L можливих підслів довжиною L - 1). Якщо таке підслово є в словнику, значення оновлюється:  
   `dp[word] = max(dp[word], dp[subword] + 1)`
4. **Пошук оптимального розв'язку:** Максимальне значення в структурі `dp` і буде шуканою довжиною найдовшого ланцюжка.

Коректність роботи алгоритму, включно з крайовими випадками (повна відсутність зв'язків між словами, слова однакової довжини, слова довжиною в один символ, складні розгалужені комбінації), перевірена за допомогою модульних тестів (бібліотека `unittest`).

# Максимальний діаметр бінарного дерева

## Умова завдання
Для заданого бінарного дерева реалізуйте функцію, яка обчислює та повертає значення максимального діаметра — найвіддаленішу відстань між двома листками. 

Максимальний діаметр у бінарному дереві визначає найбільшу відстань між будь-якою парою листків (кінцевих вузлів). Діаметр вимірюється як **кількість ребер**, які потрібно пройти, щоб дістатися від одного листка до іншого. Важливо: шлях, що утворює максимальний діаметр, не обов'язково має проходити через кореневий вузол дерева.

        self.value = value
